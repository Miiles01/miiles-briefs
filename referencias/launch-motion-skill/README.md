(https://higgsfield.ai/@sanjii/blogs/how-to-make-saas-launch-videos-with-claude-motion-skill-prompts), descargado el 2026-11-08.

lista de revisión antes de renderizar) y en references/ las plantillas de brief, storyboard (5 escenas) y propuesta
para clientes (Upwork).
